# Лабораторна робота №5 — варіант 3

**Товстоп'ят Олександр Олегович, ІО-42.** Події JavaScript та регулярні вирази.

## Запуск

Відкрийте `index.html` у сучасному браузері. Встановлення залежностей не потрібне.
Якщо браузер блокує вікно результатів, дозвольте спливні вікна для сторінки.

Для браузерних тестів потрібен локальний HTTP-сервер (наприклад, Python 3):

```powershell
git clone https://github.com/pahinets/fe-lab5.git
cd fe-lab5
python -m http.server 8766 --bind 127.0.0.1
```

Сторінка: http://127.0.0.1:8766/  
Браузерні тести: http://127.0.0.1:8766/tests/browser.html

## Завдання 1

Варіант 3: рядки **1, 4, 5, 6, 7** таблиці 2 методичних вказівок.

| Поле | Зразок |
|---|---|
| ПІБ | `Петренко П.П.` |
| Телефон | `(000)-000-00-00` |
| ID-card | `АБ №123456` |
| Факультет | `АБВГ` |
| Дата народження | `01.01.2000` |

Усі наведені приклади вигадані та не є особистими даними автора.

Прізвище має довільну довжину, допускає внутрішній апостроф або дефіс.
Літери — кириличні та латинські; ініціали, серія ID й факультет — великі.
Факультет містить рівно чотири літери. Зовнішні пробіли ігноруються.
Дата перевіряється регулярним виразом та календарною перевіркою, включно з високосними роками.
Вікових обмежень немає: їх не встановлено умовою.

Помилкові рядки підсвічуються й отримують пояснення. Коректні значення виводяться
в окремому вікні через `textContent`, без інтерпретації введення як HTML.
Дані не надсилаються на сервер і не зберігаються після закриття сторінки/вікна.

## Завдання 2

Таблиця **6 × 6**, числа **1–36**. Обробники подій призначено тільки клітинці **3**:

- наведення — випадковий колір;
- клік — колір, вибраний у палітрі;
- подвійний клік — головна діагональ **1, 8, 15, 22, 29, 36**.

Браузер генерує одинарні кліки перед `dblclick`, тому клітинка 3 також отримує колір.
З клавіатури: Tab до клітинки 3, Enter/пробіл — обраний колір,
Shift+Enter/Shift+пробіл — діагональ. Колір цифр автоматично контрастує з фоном.

## Перевірки

Node.js 18+ (або новіший), без npm-залежностей:

```powershell
node --test tests/*.test.cjs
node --check script.js
node --check validation.js
```

`tests/browser.html` містить 20 перевірок реальної сторінки в iframe:
валідація, виправлення, скидання, блокування popup, результат, таблиця та клавіатура.
Лише `window.open` підміняється для автоматичної перевірки нового документа;
справжнє відкриття вікна перевіряється окремо вручну.
Node-набір містить 12 перевірок логіки та 2 перевірки нейтральності прикладів.
